# 外部サービスの設定（運営者がやること）

MOSAIC のコード側は準備済みです。ここに書いた外部サービスの設定をすると、それぞれの機能がオンになります。
秘密の値（Secret / API キー）は **チャットに貼らず、Netlify にだけ** 入れてください。
入れ終わったら「設定した」と伝えれば、値がそろっているかの確認と再デプロイをします。

Netlify の環境変数の場所：
https://app.netlify.com/projects/mosaic-test-3008fa/configuration/env

シークレットの値は「Contains secret values」にチェックを入れ、Production・Deploy Previews・Branch deploys の 3 つに同じ値を入れます。

---

## 1. Google ログイン（仕上げ）

すでに ID とシークレットは Netlify に入っています。残りは Google 側の 3 つです。

1. **リダイレクト URI を追加**
   https://console.cloud.google.com/auth/clients?project=mosaic-512914
   「MOSAIC web」→「承認済みのリダイレクト URI」→「＋ URI を追加」
   `https://mosaicdiary.app/api/auth/google/callback` → 保存
2. **ブランディング**
   https://console.cloud.google.com/auth/branding?project=mosaic-512914
   - アプリのロゴ：入れない（入れると審査が必要になります）
   - ホームページ：`https://mosaicdiary.app`
   - プライバシーポリシー：`https://mosaicdiary.app/privacy`
   - 利用規約：`https://mosaicdiary.app/terms`
   - 承認済みドメイン：`mosaicdiary.app`
   → 保存
3. **アプリを公開**
   https://console.cloud.google.com/auth/audience?project=mosaic-512914
   「アプリを公開」→「確認」

確認：ログイン画面で「Google で続ける」を押して、ログインできれば完了。

---

## 2. Cloudflare Turnstile（ロボット対策）

無料。ドメインを Cloudflare に移す必要はありません。

1. https://dash.cloudflare.com/sign-up で無料登録
2. 左メニュー（☰）の「Turnstile」→「Add widget」
   - Widget name：`MOSAIC`
   - Hostname：`mosaicdiary.app`
   - Widget mode：**Managed**
   - Pre-clearance：No
   → Create
3. 表示された 2 つを Netlify に入れる
   | 変数名 | 値 | シークレット |
   |---|---|---|
   | `TURNSTILE_SITE_KEY` | Site Key | 不要 |
   | `TURNSTILE_SECRET_KEY` | Secret Key | **チェックを入れる** |

確認：登録画面にチェック用の枠が出て、登録できれば完了。

---

## 3. Resend（パスワード再設定のメール）

無料枠：月 3,000 通・1 日 100 通。使うのはパスワード再設定のメールだけです。

1. https://resend.com で無料登録
2. 「Domains」→「Add Domain」→ `mosaicdiary.app` を追加
3. Resend に表示される DNS レコード（通常 2〜3 行。TXT や MX）を、Netlify の DNS に追加する
   https://app.netlify.com/ →「Domains」→ `mosaicdiary.app` →「Add new record」
   種類（TXT / MX）・名前・値を、Resend の表示どおりに 1 行ずつ追加します
4. Resend に戻って「Verify」。「Verified」になるまで数分〜1 時間ほど待ちます
5. 「API Keys」→「Create API Key」（権限は **Sending access**）
6. Netlify に入れる
   | 変数名 | 値 | シークレット |
   |---|---|---|
   | `RESEND_API_KEY` | 作った API キー（`re_` で始まる） | **チェックを入れる** |
   | `MAIL_FROM` | `MOSAIC <hello@mosaicdiary.app>` | 不要 |

確認：ログイン画面の「パスワードを忘れた方」でメールアドレスを入れて、メールが届けば完了（迷惑メールフォルダも確認）。

メモ：Resend は「送る」だけのサービスです。`hello@mosaicdiary.app` 宛てのメールを受け取ることはできません。

---

## 4. ほかに Netlify で入れるもの

| 変数名 | 値 | いつ |
|---|---|---|
| `CONTACT_EMAIL` | 問い合わせを受け取るメールアドレス（Gmail でも可） | 今すぐ（プライバシーポリシー・利用規約・「パスワードを忘れた方」に表示されます） |
| `DEV_TOOLS` | **削除** | 一般公開の直前（テスト相手などの開発用ツールが消えます） |
| `REGISTRATION_CODE` | そのまま | しばらく招待制で様子を見る |
| `BASIC_AUTH_USER` / `BASIC_AUTH_PASSWORD` | **削除** | 最後（これで一般公開） |

`CONTACT_EMAIL` に `support@mosaicdiary.app` のような独自ドメインのアドレスを使うには、別途「受信」の設定（メール転送サービスなど）が必要です。最初は Gmail で十分です。

## おすすめの順番

1. `CONTACT_EMAIL` を入れる（1 分）
2. Google ログインの仕上げ（10 分）
3. Cloudflare Turnstile（10 分）
4. Resend（20〜30 分。DNS の反映待ちあり）
5. 一般公開の直前に `DEV_TOOLS` を削除 → 最後に Basic 認証の 2 つを削除

管理者ページの「🚀 一般公開の準備」で、どこまでそろったかを確認できます。
