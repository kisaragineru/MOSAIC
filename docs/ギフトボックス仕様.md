# ギフトボックスの仕様（子どもの記録へのつながり）

ギフトボックスは、親や祖父母が子どものために書きためるものです。いつか子どもが MOSAIC に参加したとき、そのまま子ども自身の記録の始まりになるように作っています。

## 基本の考え方

1. 受け取ったら、子どものものになる。書いた人の呼び名（ママ、おじいちゃんなど）はずっと残る。
2. 子どもの記録に入ったものは、最初は全部「自分だけ」。誰に見せるかは子どもが決める。
3. 書いた人の言葉は書き換えない。子どもは自分の記録として、消す・公開範囲を変える・書き足すことができる。
4. 何年も先に渡すものなので、途中で消えないようにする。

## 書くとき（記録と同じ形）

- 成長の記録：本文・写真や動画（5つまで、ギャラリーかカメラ）・日付・見出し（「＋見出しをつける」で開く）。写真だけでもよい。
- 手紙：本文・日付・見出し。写真はつけない（未来の自分への手紙と同じ）。
- 写真は記録の写真と同じ仕組みで保存する。見られるのは、その記録をボックスの中で読める人だけ。

## 受け取るとき

- 受け取りコードは、受け取り日が来てから出せる。
- アカウントで受け取れるのは 13 歳から（利用規約に合わせる）。誕生日が登録されていれば、コードを出すときと受け取るときに確かめる。13 歳より前は本（PDF）にして渡せる。
- 受け取ると、成長の記録と手紙が、写真ごと子どもの記録に複製される。
  - 日付：成長の記録はその日、手紙は書いた日（日付がない成長の記録も書いた日）。
  - 表示：「🎁 ママより」「✉️ パパからの手紙」。
  - 公開範囲：自分だけ。
  - 取扱説明書やふりかえりの章には数えない（ボックスからの引用は、これまでどおり物語の章に出る）。
- ボックス自体は閉じて「読むだけ」になる。書いた人は自分の分の控えを読める。子どもは本としても読める。
- 本（PDF）で先に渡した箱も、あとからアカウントに渡せる。箱の画面の「あとから、アカウントにも渡す」で、管理者が受け取りコードを出す（13歳から。それまでは誕生日を待つ）。受け取ると、上と同じく子どもの記録に入る。本を作った管理者は、これまでどおり全部を読める。アカウントに渡せるのは一度だけ。
- 「あなたの見方」はボックス（本）の中に残る。子どもの「人から見たあなた」への統合は次の段階で行う。

## 受け取ったあと：書いた人とつながる

- 本の画面の上に「書いてくれた人とつながる」が出る。書いた人ごとに「つながる」ボタンが一つ。
- 押すと、その人とつながり、子どもの「大切な人」に家族として入る（名前は書いたときの呼び名。例：ママ）。
- 書いた人の同意は、子どものために箱に書いたことで示されているとみなす（作品から一手でつながるのと同じ考え方）。押すのは子ども。自動ではつながらない。
- つながった瞬間は「つながるだけ」。お互いに見せるものは、あとでそれぞれが選ぶ。
- 以前にどちらかがつながりを終えた相手は出さない（終えた関係を、箱から勝手に戻さない）。
- 箱から外された書き手、退会した書き手は出ない。

## 書いた人が退会したとき

- その人の言葉・見方・写真は、書いたときの呼び名と立場のまま箱に残る。
- その人が管理者だった開いている箱は、次に参加した書き手に引き継がれる。ほかに書き手がいなければ、箱も一緒に消える。
- 退会の画面にも、このことを書いている。
