### テスト
- Postgres が止まっていたら `pg_ctlcluster 16 main start`（よく止まる）。
- テストは、変更に関係するものだけを流す（例：`npx vitest run tests/unit/basic-auth.test.ts`、`npx playwright test tests/e2e/push.spec.ts`）。全件が必要そうなとき（マイグレーション、たくさんの画面で使う部品、ログイン・権限まわりの変更など）は、理由とかかる時間を添えて運営者に提案する（運営者の希望、2026-10-29）。
- `npx vitest run`（約3分）。E2E は `pnpm build` のあと `npx playwright test`（約12分）。長いので `run_in_background` で流す。
- E2E のブラウザ：`PLAYWRIGHT_CHROMIUM_PATH=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome` を付ける（付けないと、古い場所を探して起動できないことがある）。
- テスト用DBがない環境では、`docs/DEPLOYMENT.md` の「Running the tests」のとおり、最初に mosaic_dev / mosaic_test / mosaic_e2e を作る。
- E2E は全部スマホ（Pixel 7）の設定で動く。パソコン表示を試すときは `devices["Desktop Chrome"]` の別コンテキストを作る（`storageState` を渡せば、ログインしたままにできる）。
- `pkill -f "playwright test"` は自分のシェルまで止めてしまう。`pkill -f "[p]laywright test"` を使う。
- 画面の文言は ja・en・vi の3つ。日本語と英語が同じ文字列だと単体テストが落ちる（絵文字だけの文字列も同じ）。
- 招待制（REGISTRATION_CODE）を試すときは（E2E はふだん招待制なしで動く）、`playwright.config.ts` をコピーして、ポート3200・`tests/e2e/zz*` 用の一時設定を作る。終わったら消す。
