## 作業のコツ

### デプロイの確認
- Netlify MCP の `get-project`（サイトID `f5131077-121f-480e-8432-ba0a37aadcd2`）で `currentDeploy` を見る。そのあと `get-deploy` で `commit_ref` が今回のコミットか、`state` が `ready` かを確かめる。
- ビルドには1〜2分かかる。プッシュの直後は、前の版が表示されるので注意する。
- 秘密スキャンでデプロイが止まることがある（以前、説明書に書いたチーム名で止まった）。`secret_scan_result` を見る。

### テスト
- Postgres が止まっていたら `pg_ctlcluster 16 main start`（よく止まる）。
- `npx vitest run`（約3分）。E2E は `pnpm build` のあと `npx playwright test`（約9分）。長いので `run_in_background` で流す。
- E2E は全部スマホ（Pixel 7）の設定で動く。パソコン表示を試すときは `devices["Desktop Chrome"]` の別コンテキストを作る（`storageState` を渡せば、ログインしたままにできる）。
- `pkill -f "playwright test"` は自分のシェルまで止めてしまう。`pkill -f "[p]laywright test"` を使う。
- 画面の文言は ja・en・vi の3つ。日本語と英語が同じ文字列だと単体テストが落ちる（絵文字だけの文字列も同じ）。
- 招待制（REGISTRATION_CODE）を試すときは、`playwright.config.ts` をコピーして、ポート3200・`tests/e2e/zz*` 用の一時設定を作る。終わったら消す。

### マイグレーション
- スキーマの変更：`script -qc "npx drizzle-kit generate --name 名前" /dev/null`
- 関数などの手書きSQL：`--custom` をつける。
- テスト用DBを作り直す：`bash scripts/db-reset-local.sh postgres://mosaic_owner:owner_dev_pw@localhost:5432/mosaic_e2e`
- 権限の決まりは SECURITY DEFINER 関数に置く。アプリのロール（`mosaic_app`）にはテーブルを直接触らせない。関数を作ったら REVOKE/GRANT を忘れない。
